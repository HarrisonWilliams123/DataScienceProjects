Heart Classifier:
A small Python project that trains a basic machine learning model to predict heart disease using a structured medical dataset. This was mainly a practice project to stay sharp with Python, data handling, and simple model building.

What this project does:
-Loads and cleans the heart disease dataset

-Trains a classification model using scikit‑learn

-Evaluates accuracy and basic performance metrics

-Shows a straightforward end‑to‑end ML workflow in Python

Tools Used:
-Python
-Pandas
-NumPy
-Scikit‑learn
